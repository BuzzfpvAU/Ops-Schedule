## V2 UI (2026-09-19 → 22)
- **Design:** `docs/superpowers/specs/2026-09-19-v2-ui-design.md`
- **What:** second front end in `client-v2/`, served at `/v2`, against the same API and session cookie. v1 untouched.
- **Four views:** Projects (jobs by state, planned vs rostered), Equipment (bookings, home-base toggle, clash detection, travel pads), Team (people by state, leave/TOIL/notes, unallocated work), and Project detail (drill-down from Projects: crew + kit on one timeline with an append-only per-day log).
- **Zoom vs window are separate concerns.** Zoom is pixels-per-day only (presets 102/39/12 plus −/+ steps); the window is its own state that extends as you scroll, capped at five years either way. Scroll position is tracked as a day index, not pixels.
- **Server:** two additive endpoints (`GET /api/equipment/bookings`, `POST /api/jobs/:id/day-notes` + `DELETE /api/jobs/day-notes/:id`) and one new table, `job_day_notes`. No destructive migration.
- **Tests:** 122 passing — 45 in `client-v2/test/` (date maths, bar merging, lanes, conflicts, zoom/window invariants) and 15 in `server/test/jobDayNotes.test.js`.

## V2 deploy history — read before debugging a deploy
- Prod pins to its previous version when `npm run build` fails, **silently**. Three separate faults stacked up, each masking the next:
  1. `/v2` fell through to the v1 catch-all when the bundle was missing, so a build failure looked like "V2 redirects to v1". It now returns 503 and says which failure it is.
  2. Wiring `client-v2` into `postinstall`/`build` let an optional client block the whole deploy. `postinstall` is back to its known-good form and the client-v2 build is best-effort (`scripts/build-clients.mjs`).
  3. vite was in `devDependencies`; the host installs production-only, so it never landed. Build tooling for **both** clients must stay in `dependencies` — that is why `client/` lists vite there too.
- Diagnosis path: `/api/health` → no `frontends` key means old code is serving (pipeline problem); `v2: false` means the build failed, and `/v2` shows the actual error.
